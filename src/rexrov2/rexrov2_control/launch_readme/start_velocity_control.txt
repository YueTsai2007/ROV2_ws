串级PID控制系统详解
系统架构

这是一个串级PID控制系统，包含两个控制层级：
text

遥操作/高层指令 → 速度控制(外环) → 加速度控制(内环) → 推力器管理器 → 机器人执行

各组件功能说明
1. 推力器管理器 (Thruster Manager)

    作用：将广义力指令转换为各个推力器的具体推力

    输入：来自加速度控制节点的力/力矩指令

    输出：各个推力器的转速或推力指令

2. 串级PID控制器

速度控制节点 (VelocityControl.py) - 外环

    接收位置/姿态误差或速度指令

    通过PID控制生成期望的加速度指令

    话题映射：

        输入：/$(arg uuv_name)/pose_gt (地面真实位姿)

        输出：/$(arg uuv_name)/cmd_accel (加速度指令)

加速度控制节点 (AccelerationControl.py) - 内环

    接收速度控制节点发出的加速度指令

    根据机器人动力学模型计算所需的力/力矩

    考虑惯性参数进行精确控制

3. 参数配置文件

inertial.yaml

    机器人的质量、惯性张量

    附加质量参数

    浮心、重心位置

vel_pid_control.yaml

    速度控制环的P、I、D增益

    控制限幅参数

    滤波器设置

4. 遥操作系统

    提供手动控制接口

    将手柄输入转换为速度指令

    输出到cmd_vel话题供速度控制节点使用

5. 可视化系统

    RViz提供实时状态监控

    显示机器人位姿、轨迹、传感器数据等

控制流程

    指令输入：遥操作或高层规划器生成速度指令

    速度控制：VelocityControl节点根据当前位姿和期望速度计算加速度

    加速度控制：AccelerationControl节点根据动力学模型计算所需力/力矩

    推力分配：推力器管理器将广义力分配到各个推力器

    执行反馈：机器人运动，位姿传感器提供反馈

技术特点

    串级结构：提高系统稳定性和响应速度

    模型基于：利用机器人动力学参数进行精确控制

    模块化设计：各组件独立，便于调试和维护

    多模式支持：支持自动控制和手动遥操作

这种控制系统特别适合需要精确轨迹跟踪和良好动态性能的水下机器人应用。
