推力器分配器功能详解
核心功能

推力器分配器是水下机器人控制系统的关键组件，主要负责：

    广义力到推力器推力的转换

        输入：6自由度广义力/力矩（Wrench消息）

        输出：各个推力器的具体推力指令

        实现：通过推力器分配矩阵进行数学转换

    推力器管理

        推力器状态监控

        推力限制和饱和处理

        推力器故障检测和处理

推力器分配矩阵（TAM）原理

数学表达：
text

τ = T · u

其中：

    τ = 6x1 广义力向量 [Fx, Fy, Fz, Mx, My, Mz]ᵀ

    T = 6xn 推力器分配矩阵（n为推力器数量）

    u = nx1 推力器推力向量

求解推力：
text

u = T⁺ · τ

其中 T⁺ 是推力器分配矩阵的伪逆。
参数配置说明

    reset_tam参数：

        false：使用现有的TAM文件

        true：重新计算TAM并覆盖原文件

    配置文件内容：

        推力器位置和方向

        推力器最大/最小推力限制

        推力器动力学参数

工作流程

    初始化阶段：

        加载推力器配置参数

        计算或加载推力器分配矩阵

        初始化推力器状态

    运行阶段：

        订阅/<uuv_name>/thruster_manager/input话题

        接收Wrench控制指令

        计算各推力器推力

        发布推力器控制指令

在多机器人系统中的应用

通过uuv_name参数支持多机器人场景：

    每个机器人实例有独立的命名空间

    独立的推力器分配矩阵配置

    隔离的控制指令话题

故障处理机制

    推力器故障检测

    推力重分配算法

    降级控制模式

    系统状态报告

这个推力器管理器为RexROV2提供了可靠的推力分配功能，是连接高层控制器与底层执行机构的重要桥梁。
