PD控制器加恢复力补偿算法说明
算法核心思想

PD控制器加恢复力补偿是一种结合了传统PD控制优势和物理模型补偿的控制策略：

控制律结构：
text

τ = Kp·e + Kd·ė + g(η)

其中：

    Kp·e：比例项，提供位置/姿态误差补偿

    Kd·ė：微分项，提供阻尼抑制振荡

    g(η)：恢复力补偿项，主动抵消重力和浮力效应

参数特点分析

    增益配置：

        Kp = 1000,1000,1000,1000,1000,1000：较大的比例增益确保快速响应

        Kd = 100,100,100,100,100,100：适中的微分增益提供稳定阻尼

    恢复力补偿：

        主动计算并补偿重力、浮力和浮心位置的影响

        减少PD控制器需要克服的稳态负载

        提高深度控制和姿态稳定的精度

技术优势

    结构简单：相比复杂的非线性控制器，PD结构简单可靠

    物理补偿：通过恢复力补偿显著改善控制性能

    易于调试：参数物理意义明确，调试过程直观

    计算效率：计算负担小，适合实时控制

适用场景

该控制器特别适合：

    定点悬停任务：深度和姿态保持

    低速巡航：平稳的速度控制

    基础机动：简单的轨迹跟踪

    系统验证：作为其他复杂控制器的基准对比

与其他控制器的对比
特性	PD+恢复力补偿	反馈线性化	滑模控制
复杂度	低	高	中
模型依赖	部分依赖	完全依赖	低依赖
鲁棒性	中等	低	高
计算量	小	大	中
调试难度	容易	困难	中等

这种控制器在水下机器人控制中提供了一个很好的平衡点，既利用了物理模型的先验知识，又保持了控制器的简洁性和可靠性。
