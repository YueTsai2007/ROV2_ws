1. 算法概述

滑模控制（Sliding Mode Control, SMC）是一种具有强鲁棒性的变结构控制方法，属于非线性控制理论的重要分支。该算法通过设计一个特定的滑模面，使系统状态在有限时间内被强制驱向该表面，并在到达后沿着表面滑动至平衡点，从而实现对期望轨迹的精确跟踪。

在水下机器人控制领域，滑模控制因其对系统参数变化和外部扰动的不敏感性而备受青睐。RexROV2水下机器人采用的非模型基于滑模控制器（Non-Model Based Sliding Mode Controller）进一步降低了对精确数学模型的依赖，增强了在复杂海洋环境中的适应性。

s = ė + λe
e = x_d - x 为跟踪误差（期望状态与实际状态之差）

ė = ẋ_d - ẋ 为误差的导数

λ > 0 为设计参数，决定滑模面的斜率

s 为滑模变量，当 s = 0 时系统处于滑模面上
s_x = ė_x + λ_x·e_x      # 纵向位置
s_y = ė_y + λ_y·e_y      # 横向位置  
s_z = ė_z + λ_z·e_z      # 垂向位置
s_φ = ė_φ + λ_φ·e_φ      # 横滚角
s_θ = ė_θ + λ_θ·e_θ      # 俯仰角
s_ψ = ė_ψ + λ_ψ·e_ψ      # 偏航角

2.2 控制律结构

滑模控制律采用等效控制与切换控制相结合的结构：
u = u_eq + u_sw
等效控制 u_eq：

    作用：维持系统在滑模面上滑动

    特性：基于系统标称模型设计

    目标：保证系统状态沿滑模面向平衡点移动

切换控制 u_sw：

    作用：强制系统状态朝向滑模面运动

    特性：不连续控制，提供鲁棒性

    形式：通常采用符号函数或饱和函数

在RexROV2的具体实现中，控制律形式为：
u = K·sgn(s) + Kd·s + Ki·∫s dt

3. 工作过程分析
3.1 到达阶段（Reaching Phase）

目标：将系统状态从任意初始位置驱动到滑模面

动力学特性：

    系统状态被强制推向滑模面 s = 0

    满足到达条件：s·ṡ < 0

    在有限时间内完成 s → 0
ṡ = -K·sgn(s) - Kd·s
其中 K > 0 确保到达条件的满足。
3.2 滑动阶段（Sliding Phase）

目标：沿滑模面向平衡点滑动

动力学特性：    
     系统状态被约束在滑模面上 s ≡ 0

    沿滑模面的运动由 ė = -λe 决定

    指数收敛到平衡点 e → 0

稳定性保证：
根据李雅普诺夫稳定性理论，选取李雅普诺夫函数：


V = ½s²

其导数：
Ṡ = s·ṡ < 0

保证系统全局渐近稳定。

5. 算法特性分析
5.1 优势特点

    强鲁棒性

        对系统参数变化不敏感

        能够有效抑制外部扰动

        适应水动力学模型的不确定性

    有限时间收敛

        比渐近收敛具有更快的响应速度

        提高轨迹跟踪的精确性

    设计简便性

        不需要精确的系统数学模型

        参数整定相对直观

    适用于非线性系统

        天然适合水下机器人的非线性动力学

        能够处理耦合效应

5.2 固有挑战

    抖振问题（Chattering）

        根源：不连续控制引起的开关效应

        影响：可能损坏执行机构，降低控制精度

    高频切换

        对推力器寿命的影响

        可能激发未建模 dynamics

    控制量峰值

        初始阶段可能产生较大的控制信号

        需要合理的饱和限制
