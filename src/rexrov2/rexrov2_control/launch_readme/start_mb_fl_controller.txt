代码功能说明

这个启动文件用于启动模型基于反馈线性化控制器（Model-Based Feedback Linearization Controller），与之前的滑模控制器相比，主要区别在于：
核心控制器差异

    反馈线性化控制：基于机器人精确的动力学模型，通过数学变换将非线性系统转化为线性系统

    需要模型参数：依赖model_params.yaml文件中的水动力学参数

    控制结构：使用标准的PID控制架构（Kp, Kd, Ki）

参数特点

    增益值较大：相比滑模控制，PID增益值明显更大，反映了不同的控制策略

    模型依赖：需要准确的机器人动力学模型参数

    优化方法相同：同样使用SMAC算法进行参数优化

适用场景

这种控制器在机器人模型准确已知的情况下，通常能提供更好的控制性能，但对模型精度要求较高。
