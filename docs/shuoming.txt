1.1 机器人基础控制启动,先开个终端启动
roslaunch rexrov2_gazebo start_demo_pid_controller.launch

1.2 推进器效率控制
作用：模拟推进器故障或性能下降，测试容错控制能力
例：roslaunch uuv_control_utils set_thruster_output_efficiency.launch \
  uuv_name:=rexrov2 \
  thruster_id:=0 \
  efficiency:=0.5
参数说明：
uuv_name : 机器人名称 
thruster_id : 推进器ID (0-5)
efficiency : 效率值 (0.0-1.0, 0=完全故障, 1=正常)

1.3 动态参数调整
作用: 运行时调整控制器参数，用于在线调参
例：roslaunch uuv_control_utils set_scalar_parameter.launch \
  uuv_name:=rexrov2 \
  param_name:="Kp" \
  param_value:=15000.0
参数说明：  
uuv_name : 机器人名称 (必须)
param_name : 参数名称 (如 "Kp", "Kd", "max_depth")
param_value: 参数值
param_type : 参数类型 ("double"/"int"/"bool")

2、轨迹规划节点
2.1 螺旋轨迹
作用: 执行3D螺旋运动轨迹，测试三维空间控制能力
roslaunch uuv_control_utils start_helical_trajectory.launch \
  uuv_name:=rexrov2 \
  n_turns:=2 \
  radius:=8 \
  delta_z:=5.0
参数说明:
uuv_name : 机器人名称 (必须)
n_turns : 螺旋圈数
radius : 螺旋半径 (米)
delta_z : 每圈高度变化 (米)
max_forward_speed : 最大前进速度 (m/s)
2.2 圆形轨迹
作用: 执行水平圆形轨迹，测试转向控制性能
roslaunch uuv_control_utils start_circular_trajectory.launch \
  uuv_name:=rexrov2 \
  radius:=10 \
  n_turns:=2 \
  center:="0,0,-20"
参数说明:
radius : 圆形半径 (米)
n_turns : 圈数
center : 圆心坐标 "x,y,z"
max_forward_speed : 最大前进速度 (m/s)
2.3 路径点跟踪
作用: 按照预设路径点自主航行，支持复杂航线规划
echo "x,y,z,yaw
0,0,-20,0
10,0,-25,0  
10,10,-30,1.57
0,10,-25,3.14" > ~/my_waypoints.csv

# 启动路径跟踪
roslaunch uuv_control_utils send_waypoints_file.launch \
  uuv_name:=rexrov2 \
  filename:="/home/lili/my_waypoints.csv"
文件格式说明:
CSV格式: x坐标,y坐标,z坐标,偏航角
YAML格式: 支持更多参数(速度、航向等)
YAML格式示例:
waypoints:
  - point: [0, 0, -20]
    max_forward_speed: 0.5
    heading: 0.0
  - point: [10, 0, -25]
    max_forward_speed: 0.5
    heading: 0.0
3. 环境扰动节点
3.1 定时水流扰动
作用: 设置定时、定向的水流扰动，模拟真实海洋环境
例：roslaunch uuv_control_utils set_timed_current_perturbation.launch \
  current_vel:=1.0 \
  horizontal_angle:=0.785 \
  vertical_angle:=0.0 \
  starting_time:=5 \
  end_time:=30
参数说明:
current_vel : 水流速度 (m/s)
horizontal_angle: 水平角度 (弧度, 0=东, π/2=北)
vertical_angle : 垂直角度 (弧度)
starting_time : 开始时间 (秒)
end_time : 结束时间 (秒, -1=无限)
角度参考:
0弧度 = 正东方向
π/2(1.57) = 正北方向
π(3.14) = 正西方向
3.2 随机水流扰动
作用: 高斯-马尔可夫随机水流扰动，模拟自然水流变化
roslaunch uuv_control_utils set_gm_current_perturbation.launch \
  component:=velocity \
  mean:=0.5 \
  min:=0.1 \
  max:=1.0 \
  noise:=0.1
参数说明:
component : 扰动分量 (velocity/horizontal_angle/vertical_angle)
mean : 平均值
min : 最小值
max : 最大值
noise : 噪声强度
3.3 集中扰动管理
作用: 统一管理所有环境扰动，提供集中控制接口
roslaunch uuv_control_utils start_disturbance_manager.launch \
  uuv_name:=rexrov2 \
  use_current_perturbations:=true
启动后可通过服务调用控制:
rosservice call /rexrov2/set_current_velocity "velocity: 0.8
horizontal_angle: 0.0
vertical_angle: 0.0"
3.4 手动施加力扰动
作用: 手动给机器人施加力/力矩，测试动力学响应
启动命令:
bash
roslaunch uuv_control_utils apply_body_wrench.launch \
  uuv_name:=rexrov2 \
  force_x:=100 \
  force_y:=0 \
  force_z:=0 \
  torque_z:=50 \
  duration:=5
参数说明:
force_x, force_y, force_z : XYZ方向力 (牛顿)
torque_x, torque_y, torque_z : XYZ方向力矩 (牛·米)
duration : 作用时间 (秒)
使用示例:
bash
# 向前推力
roslaunch uuv_control_utils apply_body_wrench.launch uuv_name:=rexrov2 force_x:=100 duration:=5
# 向上浮力
roslaunch uuv_control_utils apply_body_wrench.launch uuv_name:=rexrov2 force_z:=200 duration:=3
# 旋转力矩  
roslaunch uuv_control_utils apply_body_wrench.launch uuv_name:=rexrov2 torque_z:=80 duration:=4

5. 机械臂控制节点
5.1 单独控制模式
作用: 分别控制机器人底盘和机械臂
启动命令:
bash
roslaunch oberon7_control uuv_oberon7_separate_teleop.launch \
  uuv_name:=rexrov \
  model_name:=rexrov \
  joy_id:=0
操作说明:
    按住 RB 键: 控制ROV移动
    按住 LB 键: 控制机械臂运动
5.2 协同控制模式
作用: 同时控制机器人底盘和机械臂协同作业
启动命令:
bash
roslaunch oberon7_control uuv_oberon7_cooperate_teleop.launch \
  uuv_name:=rexrov \
  model_name:=rexrov \
  joy_id:=0
操作说明:
按住 RB 键: 协同控制ROV和机械臂
按住 LB+RB: 仅控制ROV移动
按住 Home+RB: 仅控制机械臂

7.3 常见问题解决
    节点启动失败:
        检查ROS master是否运行: roscore
        检查工作空间是否source: source devel/setup.bash
    服务调用超时:
        确认目标节点正在运行
        检查命名空间是否正确
    Gazebo模型加载失败:
        检查模型路径: echo $GAZEBO_MODEL_PATH
        重新启动Gazebo
